# Moonlit Hollow — Project 4 Phase 1

A phone-first Halloween exploration prototype built with HTML, CSS, and JavaScript.

## Run locally

Serve the `dist` directory with any static server, for example:

```sh
python3 -m http.server 4173 --directory dist
```

Then open `http://localhost:4173` in a browser. Use a real phone or device emulation in portrait orientation for the intended composition.
